# CONTEXT — exam-platform-web vocabulary

<!-- graffino-agentic:begin v1 -->
> The approved terms for this project. Use each term exactly as defined, in the part
> of speech given. Never swap in a synonym; never use a word on an _Avoid_ line.
<!-- graffino-agentic:end -->

**Exam** (noun) — A structured assessment consisting of questions administered to a student or candidate.
_Avoid_: test (when referring to an exam), quiz (unless formally designated as a quiz).

**Candidate** (noun) — A user registered to take an examination.
_Avoid_: testee, examinee, taker.

**Examiner** (noun) — A user authorized to create, grade, or proctor exams.
_Avoid_: teacher (unless role-specific), admin (unless platform administrator).

**Attempt** (noun) — A single instance of a candidate taking an exam.
_Avoid_: session, run.

**Submission** (noun) — The completed set of candidate answers submitted for evaluation.
_Avoid_: turn-in, finished test.
