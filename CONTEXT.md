# CONTEXT — exam-platform-web vocabulary

<!-- graffino-agentic:begin v1 -->
> The approved terms for this project. Use each term exactly as defined, in the part
> of speech given. Never swap in a synonym; never use a word on an _Avoid_ line.
<!-- graffino-agentic:end -->

**Exam** (noun) — A structured assessment consisting of questions administered to a student or candidate.
_Avoid_: test (when referring to an exam), quiz (unless formally designated as a quiz).

**Candidate** (noun) — A user registered to take an examination.
_Avoid_: testee, examinee, taker.

**Examiner** (noun) — A user authorized to create, grade, or proctor exams.
_Avoid_: teacher (unless role-specific), admin (unless platform administrator).

**Attempt** (noun) — A single instance of a candidate taking an exam.
_Avoid_: session, run.

**Submission** (noun) — The completed set of candidate answers submitted for evaluation.
_Avoid_: turn-in, finished test.

**Subject 1** (noun) — The first section of an exam consisting of auto-gradable foundational items evaluating definitions and direct applications without partial credit.
_Avoid_: part 1.

**Subject 2** (noun) — The second section of an exam consisting of multi-step problem-solving questions evaluated manually with partial credit.
_Avoid_: part 2.

**Baseline Points** (noun) — Unconditional baseline points (10 points / *punct din oficiu*) added to the exam score to yield a 1 to 10 final grade scale.
_Avoid_: bonus, curve, free points.

**Variant** (noun) — A specific parameter or question set variation administered to minimize copying while preserving equivalent mathematical difficulty.
_Avoid_: row, seat version.

**Item Analysis** (noun) — Post-examination statistical evaluation measuring item difficulty and discrimination index across attempts.
_Avoid_: question stats.

**Grace Period** (noun) — The 30-second server buffer accepting in-flight submissions delayed by network latency after timer expiration.
_Avoid_: overtime, extension.
