## Live environment (Render, D-014)
- Site: https://exam-platform-web-ip0s.onrender.com
- API: https://exam-platform-api-hwy2.onrender.com (`/up`, `/api/health`)
- Deploys from `main` through the Blueprint "Digital Evaluation Platform" (`render.yaml`).
- **Database expiry:** the free `exam-platform-db` was created 2026-11-22. It expires around
  **2026-12-22** and is deleted around **2027-01-05** with its data. Decision deferred by the
  user (options: finish before then, upgrade for a month or two, recreate before expiry, or a
  free external Postgres, which would need a PROPOSAL against D-014). Back up the pilot
  results right after the pilot whatever is decided.
- Free web services sleep after 15 minutes idle; the first request then takes up to a minute.

## Risks
- **Catalog items the client ruled out** (negative marking, partial credit on multiple choice,
  ordering questions): the decisions win (D-005, README §7), and SUBMISSION.md says so
  honestly instead of claiming OK.
- **Uploads and the scheduled job on Render** are settled without paid features (D-048 object storage; D-044 external ping); set both up early in P6 and check them on the live site.

## Out of scope
Everything in README §7 (proctoring, LMS integrations, plagiarism detection, offline mode,
in-exam chat, ordering questions), plus anything that depends on an open question until it is
answered.
